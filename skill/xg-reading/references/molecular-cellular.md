# Molecular and cellular mechanism

## Typical argument patterns

- phenotype → candidate factor → perturbation → rescue → pathway placement → physiological validation;
- localization change → interaction evidence → domain or residue mapping → functional consequence;
- stimulus → signaling kinetics → downstream transcription or phenotype → feedback regulation.

Follow the paper's actual order rather than forcing these patterns.

## Depth checks

- Distinguish expression change from activity change and localization change.
- Check whether knockdown uses multiple independent reagents and whether knockout phenotypes could reflect adaptation.
- Evaluate overexpression dose and nonphysiological localization.
- For rescue, check expression level, resistance to the perturbation reagent, relevant isoform, and restoration of the correct compartment.
- Separate necessity, sufficiency, and directness.
- For epistasis, check whether intervention order truly places factors upstream or downstream.
- For interaction claims, distinguish co-IP, pulldown, proximity labeling, colocalization, and direct biophysical binding.
- For microscopy, inspect segmentation, field selection, cell count, blinding, scale bars, and independent quantification.
- For Western blots, inspect loading controls, linear range, full blots, biological repeats, and whether band quantification matches the image.
- For reporter assays, check normalization, promoter specificity, and whether the reporter reflects the claimed endogenous process.
- For cell death, proliferation, differentiation, or senescence, require functionally appropriate and preferably orthogonal assays.

## Stronger causal evidence

Confidence increases with independent perturbations, dose/time coherence, orthogonal assays, rescue, epistasis, direct binding or catalytic evidence, endogenous validation, and replication across models. No single item substitutes for the others.

## Common overclaims

- “regulates” based only on correlation;
- “directly binds” based only on co-IP or colocalization;
- “controls pathway X” based only on one marker;
- “cell autonomous” without separating secreted or neighboring-cell effects;
- “general mechanism” from one transformed cell line.
